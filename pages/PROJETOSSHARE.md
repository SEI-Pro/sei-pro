# Sharing projects (updated)

> The Google Spreadsheet sharing flow is **historical**. Projetos now stores data locally (and optionally syncs via the Atividades API).

## Current options

1. **In-panel share table** — open a project and use the share action to list users and permissions (`leitura` / `edicao`).
2. **JSON export / import** — export projects from the toolbar and send the file to colleagues; they import it from the same toolbar.
3. **Atividades backend** — if your unit uses the remote API, sharing follows that backend’s permission model (`share_projeto`).

## Historical Sheets steps

Previously you had to share the Google Spreadsheet and grant edit/view access in Google Drive. That is no longer required for Projetos.
