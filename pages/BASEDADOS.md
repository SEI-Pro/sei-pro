# Google Spreadsheet as database (historical)

> **Historical.** The Projetos feature no longer uses Google Sheets. See [PROJETOS.md](./PROJETOS.md) for the current local-first flow.

This page previously explained how to copy a spreadsheet template, enable the Google Sheets API, configure OAuth consent, and create a Client ID / API key for SEI Pro. That path was discontinued when the Google API integration stopped working and was later removed from the runtime.

If you still need a shared spreadsheet for **formularios** or **process sync** features, keep using those feature-specific guides — they are separate from Projetos.
