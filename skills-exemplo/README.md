# Skills de exemplo

Modelos de **skill** para o [Agente de IA](../pages/AGENTEIA.md) do SEI Pro: instruções da sua
unidade que o agente carrega quando o pedido é daquele assunto.

Como usar na sua unidade:

1. Copie estes arquivos para um repositório **público** do seu órgão (ou crie os seus);
2. No SEI Pro, abra o agente → **Configuração → Skills → Skills da equipe**;
3. Informe o endereço da pasta (`https://github.com/seu-orgao/seu-repo/tree/main/skills`) e ligue
   **Manter sincronizada**;
4. Quem cuida do padrão edita os arquivos; todo mundo da unidade recebe a atualização.

Cada arquivo `.md` da pasta vira uma skill. O título (`# Assim`) ou o `name:` do cabeçalho vira o
nome; o `README.md` fica de fora.

> Estes arquivos são exemplos genéricos, escritos para serem adaptados. Eles não substituem o
> manual de redação oficial nem as normas do seu órgão.
